## Краткое описание

Интернет-магазин техники **TechShop** — четыре страницы на Bootstrap 5.3.8 с динамическим каталогом из JSON. Реализованы: главная с hero-блоком и преимуществами, каталог с фильтрами и сортировкой, страница товара с табами и похожими товарами, форма заявки с отправкой на email.

## Стек

- **Bootstrap 5.3.8** — сетка, компоненты, утилиты (через CDN)
- **Bootstrap Icons 1.11.3** — векторные иконки (через CDN)
- **Inter** — шрифт (Google Fonts)
- **Vanilla JavaScript** — без фреймворков, только `fetch`, DOM API и `IntersectionObserver`
- **JSON** — данные каталога (`data/catalog.json`)

## Как запустить

Проект использует `fetch()` для загрузки JSON — **нужен локальный сервер** (по CORS нельзя открыть через `file://`).
