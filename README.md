## Краткое описание

**Техника у Бориса** — интернет-магазин современной техники: смартфоны, ноутбуки, планшеты, наушники, умные часы, телевизоры, игровые консоли и фотоаппараты. 25 товаров в 8 категориях.

Проект состоит из четырёх страниц и полностью собран на Bootstrap 5.3.8. Реализованы все обязательные Bootstrap-компоненты: сетка, `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, формы, `tabs` и `accordion`.

| Страница | Содержание |
|---|---|
| `index.html` | Главная: navbar, hero-блок со статистикой, категории, популярные товары, акция, преимущества, отзывы, accordion с частыми вопросами, подписка, футер |
| `catalog.html` | Каталог на Bootstrap-сетке: фильтр по категориям, сортировка, карточки товаров со значками и кнопками |
| `product.html` | Страница товара: изображение, цена, badge, характеристики, кнопки действия, tabs (доставка/гарантия/возврат), похожие товары, модальное окно покупки |
| `order.html` | Форма заявки: контактные данные, input-group для телефона, form-select товара, form-check согласия, сводка заказа, alert об успехе/ошибке |

Данные товаров вынесены в `data/catalog.json` и подгружаются через `fetch()`, поэтому карточки, страница товара и сводка заказа строятся из одного источника.

## Используемый фреймворк

**Bootstrap 5.3.8** + **Bootstrap Icons 1.11.3**. Дополнительно используется шрифт Inter (Google Fonts).

Альтернативные фреймворки (Tailwind CSS, Bulma) не применялись — выбран основной вариант по методическим указаниям.

## Способ подключения Bootstrap

Bootstrap подключён **локально**, без CDN (дополнительное задание). Файлы фреймворка размещены в папке `vendor/`:

- `vendor/bootstrap/css/bootstrap.min.css` — compiled CSS Bootstrap 5.3.8;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JS Bundle (Popper + все интерактивные компоненты);
- `vendor/bootstrap-icons/bootstrap-icons.min.css` — иконки;
- `vendor/bootstrap-icons/fonts/bootstrap-icons.woff2` (+ `.woff`) — шрифт иконок.

Порядок подключения на каждой странице — сначала фреймворк, затем собственные стили, чтобы `custom.css` мог переопределять Bootstrap:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="vendor/bootstrap-icons/bootstrap-icons.min.css">
<link rel="stylesheet" href="css/custom.css">
<!-- ... -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/app.js"></script>
```

Bootstrap JS Bundle необходим для раскрывающегося мобильного меню (`navbar-toggler`), модального окна, вкладок (`tabs`) и `accordion`.

## Изображения товаров

Фотографий товаров в свободном доступе для всех 25 позиций нет, поэтому в проекте используются **локальные SVG-плейсхолдеры по типу товара**: `images/smartphone.svg`, `images/laptop.svg`, `images/tablet.svg`, `images/headphones.svg`, `images/watch.svg`, `images/tv.svg`, `images/console.svg`, `images/camera.svg`. В каждом — ровный синий фон и белая надпись с типом товара («Смартфон», «Ноутбук», «Телевизор» и т.д.). Внешних ссылок на картинки нет — проект не зависит от сторонних сервисов и работает офлайн.

Если нужно подставить настоящие фотографии:

1. положите файл в `images/`, например `images/06.jpg`;
2. в `data/catalog.json` у нужного товара замените поле `"image"` на `"images/06.jpg"`.

Поле `"image"` — единственное место, где задаётся картинка: она автоматически появится в каталоге, на главной, на странице товара и в сводке заказа. Если файл не найдётся, `js/app.js` подставит `images/placeholder.svg`.

## Как запустить

Проект использует `fetch()` для загрузки `data/catalog.json`. По политике CORS браузер не даёт читать локальный JSON через `file://`, поэтому нужен локальный сервер.

**Вариант 1 — Python:**

```bash
cd KR2
python -m http.server 8000
```

Открыть <http://localhost:8000/index.html>.

**Вариант 2 — VS Code:** расширение Live Server, пункт *Open with Live Server*.

**Вариант 3 — GitHub Pages:** адрес вида `https://<username>.github.io/kr2-bootstrap-shop/`.

## Реализованные компоненты Bootstrap

- `container` — контейнер на всех страницах;
- `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-3`/`g-4` — адаптивная 12-колоночная сетка;
- `navbar` (navbar-expand-lg, navbar-toggler, collapse) — навигация на всех страницах, мобильное меню раскрывается;
- `card` (card-body, card-img-top, h-100) — карточки товаров;
- `btn` — варианты `btn-primary`, `btn-outline-primary`, `btn-outline-success`, `btn-outline-light`, `btn-secondary`, `btn-light`, `btn-lg`;
- `badge` — метки «Хит», «Новинка», «Скидка», «Нет в наличии»;
- `alert` — `alert-info`, `alert-success`, `alert-danger`, `alert-secondary`;
- `modal` — окно заявки/покупки (открывается кнопкой с `data-bs-toggle="modal"`, закрывается `data-bs-dismiss`);
- `form-control` — текстовые поля, e-mail, телефон, комментарий;
- `form-select` — выбор товара и сортировка в каталоге;
- `input-group` + `input-group-text` — поле телефона с префиксом «+7»;
- `form-check` — чекбокс согласия на обработку данных;
- `tabs` (nav-tabs, tab-content, tab-pane) — доставка / гарантия / возврат на странице товара;
- `accordion` — блок «Частые вопросы» на главной;
- `breadcrumb`, `list-group` и utility-классы (`d-flex`, `gap-*`, `text-muted`, `shadow-sm`, `fw-bold`, `h-100`, `w-100`).

## Что сделано самостоятельно (сверх базовой инструкции)

1. **Локальное подключение Bootstrap** — файлы фреймворка лежат в `vendor/bootstrap/`, CDN не используется.
2. **JSON-каталог и динамический рендеринг** — 25 товаров в `data/catalog.json`, все списки и страница товара строятся одним модулем `js/app.js`.
3. **Каталог с фильтрами и сортировкой** — фильтр по 8 категориям со счётчиками, сортировка по цене, рейтингу и новизне; категория передаётся через `?category=`.
4. **Страница товара** — выбор товара по `?id=`, характеристики, кнопка «Купить» открывает модальное окно с предвыбранным товаром, блок похожих товаров.
5. **Сценарий заявки** — валидация полей, состояние кнопки «Отправка…», `alert` об успехе/ошибке, сводка заказа с расчётом доставки (бесплатно от 5000 ₽) и итоговой суммой.
6. **Единый визуальный стиль** — `css/custom.css` задаёт фирменные CSS-переменные, hero-блок, карточки, футер и мягкое появление блоков при прокрутке; компоненты Bootstrap при этом не переписываются.
7. **Собственный набор изображений** — SVG-плейсхолдеры по типам товаров, без внешних зависимостей.
8. **Адаптивность** — сетка построена на `col-12` → `col-md-*` → `col-lg-*`, карточки и сайдбар каталога перестраиваются, отступы заданы через `g-*`.

## Как проверить работу

1. Открыть `index.html` через локальный сервер — загрузятся популярные товары, раскроется `accordion` с вопросами.
2. Уменьшить окно до мобильной ширины — меню свернётся в `navbar-toggler`, карточки встанут в одну колонку.
3. Перейти в «Каталог» — поработать с фильтром категорий и сортировкой, нажать «Подробнее» на карточке.
4. На странице товара открыть вкладки «Доставка / Гарантия / Возврат» и нажать «Купить» — откроется модальное окно с выбранным товаром.
5. На странице «Заказ» выбрать товар (сводка пересчитает доставку и итог), отправить форму без согласия — сработает валидация; с согласием — появится `alert` об успехе.
